# Networking Module

## Overview

This module introduced the core networking concepts required for modern IT, Cloud, and DevOps environments. It covered how devices communicate across networks, how cloud resources are connected securely, and how web services are made accessible over the Internet.

The practical work focused on deploying and configuring networked services in Microsoft Azure using Linux, while applying concepts such as SSH, HTTP, DNS, and cloud networking.

---

## Topics Covered

- OSI and TCP/IP Models
- IPv4 Addressing
- Public and Private IP Addresses
- Subnetting
- VLANs
- Routing and Switching
- NAT (Static, Dynamic and PAT)
- DNS and Common DNS Records
- HTTP and HTTPS
- Common Network Ports
- Firewalls
- Azure Networking
- AWS Networking Concepts
- SSH
- NGINX Web Server
- Basic Linux Networking Commands
- Network Troubleshooting

---

## Practical Work

During this module I completed several practical exercises, including:

- Deploying an Ubuntu Server virtual machine in Microsoft Azure.
- Connecting securely to the server using SSH.
- Installing and configuring the NGINX web server.
- Creating and hosting a custom HTML webpage.
- Configuring Azure networking to allow HTTP traffic.
- Configuring Cloudflare DNS records to point a custom domain to the Azure virtual machine.
- Verifying connectivity using Linux networking tools such as `curl` and `ss`.
- Troubleshooting DNS, networking, and web server connectivity issues.
